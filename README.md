# kotoba — Xのリプライを考える作業室

相手の投稿を読み、「具体的に何が響いたか」「何を試してみたいか」を自然な日本語にするWebツールです。構成の異なる3案から選び、自分の言葉に編集してコピーできます。質問を添える案も選択できます。

## 使えること

- 投稿本文、相手の名前、今回の気づき・試したいことを入力
- 自然で丁寧／やわらかめ／短く端的の文体を選択
- 気づき・実践意欲・質問の方向性、文章の長さ、絵文字を指定
- 3案を作成・再生成し、画面上で本文を編集
- Xの重み付き文字数を表示。日本語、絵文字、URLにも対応し、280を超えるとコピーを止める
- コピー、ブラウザ内への保存、元投稿の確認、保存した文章の検索・削除
- いつもの文体の設定、スマートフォン対応、キーボード操作

Xへの自動投稿・自動リプライ・URLからの投稿取得は行いません。本文を貼り付けて利用します。返信やフォロワー増加を保証するものではありません。

## サーバーなしで使うHTML版

`exports/kotoba.html` をブラウザで開くと、インストールやサーバー起動をせずに利用できます。投稿からの3案生成、編集、コピー、保存、検索に対応し、ネットワーク接続なしで動きます。HTML版は文章パターン生成のみです。フォントは端末のものを使います。保存はそのブラウザ内に限られ、ファイルの移動やブラウザによって保存領域が変わる場合があります。

HTML版の再作成は `npm run build:standalone` で行います。生成物はGit管理対象外です。サーバー版と共通の画面・生成処理を使っています。

## 開発環境

Node.js 22.12以降（この環境では24.19）とnpmを使います。データベースやXの認証は不要です。

```sh
cd /workspace/X-
npm ci --cache /workspace/.npm-cache --no-audit --no-fund
npm run dev
```

フロントエンドはポート5173、APIは3001で起動します。`npm run dev` は両方を起動し、終了時に両方を止めます。既存のチェックアウトをそのまま利用し、worktreeは作成しません。

依存パッケージはnpmレジストリから取得します。日本語・英字フォントは同梱して配信するため、ブラウザから外部フォントサービスへの接続は不要です。

## 生成モード

### 文章パターン（標準・キー不要）

投稿の一節と用意した表現を組み合わせます。投稿と追加した気づきは、このアプリのサーバーだけで処理し、外部AIへは送信しません。意味理解を行うAIではないため、特に長い投稿の省略部分・引用のつながり・質問の重複は、送る前に確認してください。長さの設定で収まらない追加の気づきは省略される場合があります。

### AI（任意）

サーバーに `REPLY_API_KEY` があればOpenAIのChat Completions APIを使用します。投稿本文・相手の名前・気づき・選択した設定がOpenAIへ送信されます。API利用料金が別途かかります。秘密情報を含む投稿は入力しないでください。

環境のシークレット設定で `REPLY_API_KEY` を設定し、許可先を `api.openai.com` にしてください。ローカルで利用する場合は `.env.example` を `.env` にコピーし、キーを記入できます。実際のキーをGit管理やチャットに含めないでください。`.env` はGit管理対象外です。

非機密の設定 `REPLY_MODEL` でモデルを変更できます。初期値は `gpt-4.1-mini` です。設定後にサーバーを再起動してください。AIの認証・利用上限・接続・出力形式のエラーは画面に表示し、文章パターンへ黙って切り替えることはありません。出力は構造と文字数を検査します。1接続元につき1分間に10回を上限とします。

現在のセットアップでは文章パターンモードを検証済みです。AIの実通信はAPIキーが未設定のため未検証です。APIキーを設定後、実際に3案が生成されることを確認してください。

## ビルドと本番起動

```sh
npm run build
npm start
```

ビルドした画面とAPIをポート3001で配信します。`PORT` で変更できます。プロセス起動だけでなく、以下のリクエストでAPIが3案を返すことを確認します。

```sh
curl --fail --silent http://127.0.0.1:3001/api/health
curl --fail --silent http://127.0.0.1:3001/api/generate \
  -H 'Content-Type: application/json' \
  --data '{"post":"発信は完璧を目指さず、小さな気づきを積み重ねる。","directions":["insight","action"]}'
```

このアプリは個人用の開発環境を想定しています。ログイン機能はありません。APIキーを設定したままインターネットへ公開する場合は、別途アクセス制限が必要です。

## 検証

```sh
npm test
npm run build
npm run build:standalone
# 別ターミナルで npm run dev を起動してから実行
npm run test:browser
```

ブラウザテストは標準で `/usr/bin/chromium` を使います。別の環境では `CHROMIUM_PATH` で実行ファイルを、`TEST_BASE_URL` で起動済みサーバーを指定できます。本番ビルドにも同じテストを適用できます。

生成処理のテストは文字数、絵文字、質問の保持、文体、追加文、再生成、入力検証を確認します。ブラウザテストは生成・連続編集・コピー・保存・再読込・検索・削除、エラーからの再試行、文体設定、スマートフォン、APIの入力チェックを確認します。

## データの保存先

保存したリプライといつもの文体は、このブラウザのlocalStorageに保存します。他の端末とは同期しません。ブラウザデータを削除すると保存内容も消えます。サーバーは投稿・生成結果をファイルやデータベースに保存しません。AI利用時のデータの扱いは接続先のサービス設定にも依存します。
